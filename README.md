## Importante sobre os scripts originais
Os arquivos CSS e JavaScript separados não foram enviados. Este pacote inclui CSS/JS novos, reconstruídos a partir do HTML enviado; por isso, a aparência e algumas interações podem diferir da versão anterior. Para preservar exatamente todos os recursos antigos, substitua esses arquivos pelos originais e mantenha o ajuste do rodapé no CSS.
